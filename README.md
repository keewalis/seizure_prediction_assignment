# Seizure Prediction Assignment

This project investigates how preprocessing choices, model complexity, regularization strategies, and class imbalance handling affect generalization performance in seizure prediction tasks.

## Main Model
Logistic Regression was used as the baseline model.

## Experiments Performed
- Baseline Logistic Regression
- Preprocessing Pipeline A: Imputation → Standard Scaling → Feature Selection
- Preprocessing Pipeline B: Imputation → Standard Scaling → PCA
- Regularization Study: L1, L2, Elastic Net
- Class Imbalance Handling: Class Weighting, SMOTE, Random Undersampling
- Overfitting and Underfitting Demonstration

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- PR-AUC
